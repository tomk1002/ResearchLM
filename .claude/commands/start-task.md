Start working on the next task in the queue.

## Protocol

1. Read `docs/planning/TASK_QUEUE.md` for next task
2. Read the task's GitHub issue: `gh issue view $ARGUMENTS`
3. Create feature branch: `git checkout -b feat/$ARGUMENTS-[brief-name]`
4. Update `docs/context/CURRENT_TASK.md` with task details
5. Read appropriate agent file based on task type
6. Begin work following that agent's protocol

## Output

Confirm task start and show:

- Task description
- Acceptance criteria
- Files to be modified
- Estimated complexity
