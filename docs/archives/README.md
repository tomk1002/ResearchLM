# Archives Directory

This directory stores historical context that is no longer actively needed.

## Structure

```
archives/
├── 2025-01-15/
│   ├── completed-feature-x.md
│   └── old-exploration-notes.md
└── 2025-01-20/
    └── refactored-component-context.md
```

## When to Archive

- After completing a task
- When context is no longer relevant to next 3 tasks
- During context pruning sessions

## Retrieval

If you need archived information:

1. Check the date folders
2. Read relevant archived files
3. Extract only what's needed for current task
4. Do NOT restore entire archives to active context
